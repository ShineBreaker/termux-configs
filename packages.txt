# Termux 软件列表 (显式安装的顶层包，依赖在安装时自动解析)
# 生成方式: bash setup.sh export (apt-mark showmanual，不含自动安装的依赖)
#
# 使用说明:
#   - 每行一个软件包名，# 开头的行是注释
#   - bash setup.sh install 从本列表批量安装
#   - 不需要的包直接删行或注释掉即可
#
# ── 一次性迁移 (仅旧列表时代安装的设备需要执行) ──
#   旧版 export 导出全量包并逐个安装，~100 个传递依赖被错误标记为
#   manual。先按需删减本清单，然后在 Termux 真机执行:
#
#     apt-mark auto $(apt-mark showmanual)   # 全部转为自动安装
#     xargs apt-mark manual < packages.txt   # 本清单恢复为显式安装
#     bash setup.sh export                   # 重新导出(此后只含顶层包)
#
#   之后 apt autoremove 可安全回收未白名单的依赖包。
